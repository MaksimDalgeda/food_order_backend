# HogRider Food Order Backend

Backend API for the HogRider food ordering platform built with ASP.NET Core and .NET 8.

This project was part of a larger team project that included:

- Android application
- Backend API (this repository)
- Recommendation service

The recommendation service uses AI to generate personalized food recommendations based on user preferences and activity.
